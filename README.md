# Painel Comercial - Power BI

### Descrição
Este repositório contém um painel comercial desenvolvido no Power BI para análise interativa de dados comerciais. O projeto utiliza queries SQL para extrair e preparar os dados necessários para o painel.

### Funcionalidades
- Análise de Faturamento por período e por produto.
- Comparação com o ano anterior (YoY).
- Indicadores de Ticket Médio e Quantidade de Pedidos.
- Visualização interativa para insights rápidos.

### Queries SQL
As queries SQL utilizadas no projeto estão disponíveis na pasta `Queries_SQL/`. Cada arquivo contém a query correspondente às tabelas utilizadas no painel:

- **`clientes_query.sql`**: Extração de dados de clientes.
- **`produtos_query.sql`**: Extração de informações detalhadas de produtos.
- **`vendas_query.sql`**: Extração de dados de vendas realizadas.

As queries foram otimizadas para garantir que os dados sejam consistentes e relevantes para o painel.
